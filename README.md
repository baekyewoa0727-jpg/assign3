Problem & Solution : 
1. 개발중 margin과 padding의 요소가 헷갈렸고, 원하는 방식대로 구성이 되지 않았습니다. 
2. 과제를 저장하고 관리하는 과정에서 git의 사용이 여전히 익숙하지 않고 어렵습니다. ai에게 질문했지만, 질문의 요청이 잘못되었는지 몇번 과제 저장에 실패한 부분이 아쉽습니다

Reflection : 
add.html에서 친구를 추가하는 페이지를 따라 만들때, 각 요소를 button기능을 사용해서 만들려고 했다. 그러나 button의 2열 3행 나열 방법을 모르겠어서 ai를 활용했습니다. 여기서 input 과 select 기능이 있다는것을 알게 되었고 활용해볼 수 있었습니다.
